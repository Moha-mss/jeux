PIXEL OCEAN

Trouve les 8 balises le plus vite possible. Les îles bloquent le bateau.
Mobile : glisse le doigt dans la direction où tu veux aller, sur 360 degrés.
Maintiens BOOST (en bas à droite) pour accélérer.
PC : flèches ou ZQSD, ou clic maintenu vers où aller. Espace pour le boost, R pour les pixels.
Taille des pixels :
Monde de 2048 x 2048 généré par la carte graphique. Zéro polygone.
